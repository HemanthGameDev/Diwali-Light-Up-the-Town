# SurfaceWeaver Lite / Pro Plan

This is a proposed feature split, not a final store listing.

Unity's current submission guidelines permit a Lite edition with fewer features, but the features included in Lite must have the same functionality as the corresponding Pro features. Avoid DRM, account checks, time limits, watermarks, disabled controls or artificially crippled operations.

| Feature | Lite | Pro |
|---|---:|---:|
| Static custom mesh target | Yes | Yes |
| URP material output | Yes | Yes |
| Base + 2 overlay layers | Yes | Yes |
| Basic round brush presets | Yes | Yes |
| Paint / erase / fill | Yes | Yes |
| PNG mask save/load | Yes | Yes |
| Undo / redo | Yes | Yes |
| UV diagnostics | Basic | Advanced visual diagnostics |
| Custom brush alpha library | — | Yes |
| Extended layer stack | — | Yes |
| Spline/path painting | — | Yes |
| UV overlap visualization | — | Yes |
| Seam padding/dilation controls | Basic export padding | Advanced configurable dilation |
| Batch target/profile tools | — | Yes |
| Advanced material recipe presets | — | Yes |

The exact layer counts, resolutions and feature list must be tested before publication. Do not introduce artificial quality reductions to features that exist in both editions. Lite should be a genuinely useful tool on its own.

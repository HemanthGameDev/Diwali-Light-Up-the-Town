## Test interpretation
- Preview.1 tests are deterministic EditMode unit tests over pure processors and serialized data models.
- Preview.2 adds GPU-backed Editor tests. They are ignored when the test host has no supported graphics device or the required mask stamp shader is unavailable. A skipped GPU test is not a pass.
- Multi-target engine tests validate the per-target GPU history primitive; they do not replace manual testing of the Multi-Mesh Painter's Scene View event routing and grouped Undo controller.
- Manual integration tests remain mandatory before the v0.9 milestone can be marked complete.
